列表（`list`）是Rime中内置的一种可变数据类型，它是由有序的有限元素组成的集合，它的不可变类型为`FrozenList`（内置于`freeze`模块）。在本篇我们将这两个类型一起介绍。

## 声明
列表使用方括号`[]`包裹，内部的元素使用`,`分，例如：`[1, 2, 3]`、`["123, "456"]`、`["123", 12]`。

### 类型
不作为变量的值的列表解释器自动推断出它的类型，例如：`[1, 2, 3]`被自动推断为`list[int]`。作为变量赋值的时，解释器检查它的类型能否分配给变量注明的类型，再进行赋值，例如：
```
a: list[any] = [1, 2, 3] // 类型被推断为list[int]，list[int] -> list[any] 可行
b: list[string] = [1, 2, 3] // list[int]不可分配给list[string]报错
```

### fresh与型变
当列表内的所有元素均有`fresh`标记时，列表被视为是`fresh`的。（`fresh`标记详见[[可变对象与不可变对象#fresh标记]]）

当一个`fresh`的`list`对象被赋值或传递时，仅要求被赋值的变量的类型能被分配（例如：`list[int] -> list[any]`）
当一个`list`对象本身要再次赋值到一个新变量时，要求新变量的类型要跟对象的类型一致，即：
```
// 在这个例子中我们假设Dog，Cat是Animal的子类
a: list[Dog] = [Dog(), Dog()]
b: list[Animal] = a          //报错
c: list[Cat] = a             //报错
d: list[Dog] = a             //通过
```

`FrozenList`是协变的，因此允许：
```
b: FrozenList[Animal] = frozen(a) // 或FrozenList(a)
```

关于[`frozen`](可变对象与不可变对象.md#frozen)、[`clone`](可变对象与不可变对象.md#clone)、[`fresh`](可变对象与不可变对象.md#fresh标记)的用法详见[[可变对象与不可变对象]]。

## 打包与拆包
本部分所介绍的内容在**函数***TODO!* 也有介绍。

在`[]`内使用`...a`（`a`是一个变量名）可以将一个列表拆解到另一个列表中。`...a`的位置也决定插入后元素的位置。例如：
```
a: list[int] = [1, 2, 3]
b: list[int] = [4, 5, 6, ...a]  // 结果是[4, 5, 6, 1, 2, 3]
b = [4, 5, ...a, 6] //结果是 [4, 5, 1, 2, 3, 6]
```

在函数定义时，可以允许传入不定长的参数（详细说明在另有再函数部分）。例如：
```
func test(name: string, ...items: string | int) {
     // 再函数内部，items是list[string | int]
}

test("name1", 1, 2, 3, 4, 5, 6)
test("name2", "1", "2", 3, 4)
```

传参时，也可以使用`...a`拆包后传递。例如：
```
func test(...items: string) {}

a: list[string] = ["hello", "world", "rime"]
test(...a)

func test2(name1: string, name2: string) {}

// 非可变长参数也可以用，但要注意长度
b: list[string] = ["hello", "rime"]d
test2(...b)
```

## 方法与属性

### `@getItem`与`@setItem`方法
列表可以通过下标访问与修改，修改和访问超出列表的索引的元素时会报错。
`FrozenList`不允许`@setItem`方法。

### `@getSlice`与`@setSlice`方法
列表可以通过切片访问和修改，格式为`a[<start>:<stop>:<step>]`。当下`[]`中包含冒号`:`，会调用

### `get`方法
`get(index: int, defualt: any = null)`根据索引获取一个元素，不存在将返回一个默认值（默认为`null`）。

### `indexOf`方法
`indexOf(obj: T) -> int?`查找一个元素在列表中的位置，返回元素的索引，不存在返回`null`。

### `forEach`方法
`forEach`方法传入一个可调用对象`callable`，遍历列表的每一个元素并作为参数传递给那个可调用对象。

### `append`方法
`append(...items: T)`传入一个或多个元素，将它追加到末尾。
`FrozenList`不允许`append`方法

## `insert`方法
`insert(index: int, ...items: T)`，在特定位置追加一个或多个元素。
`FrozenList`不允许`insert`方法

### `length`属性
`list`上是`property`方法。返回列表的长度。

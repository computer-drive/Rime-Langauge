# 字符串
字符串（`string`）是一个不可变的对象，期名称是`string`，用于表示字符序列。字符串使用双引号`""`、单引号`''` 、反引号<code>``</code>来表示。
字符串是跨行的，解释器读取时从一个引号读取到下一个引号。例如：
```
a: stirng = "你好，世界！
你好，Rime！
"
```
若要在相应引号包裹内的字符串表示相同的引号，使用其他引号，或在引号前添加`\`转义字符。例如：
```
a: string = "I'm a student."
b: string = 'She said, "My name is Lisa."'
c: string = "She said, \"I'm a student.\""
```
反引号包裹的字符串可以被格式化，在字符串内添加`{}`，`{}`内部将被视为一个表达式插入到字符串内，若表达式不是字符串，解释器还会尝试将其转换为字符串。例如：
```
b: int = 5
a: string = `数字：{b}，数字加一：{b + 1}`
```

## 下标访问
字符串可以通过下标访问，访问的结果仍是一个字符串。例如：
```
a: string = "你好，世界！"
a[0] // 结果是'你'
```

## length
字符串的`length`属性可以获取字符串的长度，返回一个`int`。例如：
```
// 借用上面的例子`a`
a.length // 结果是 6
```

## indexOf
字符串的`indexOf`方法可以获取另一个字符串在此字符串内的位置，返回另一个字符串的第一个字符在此字符串的下标，返回一个`int?`，找不到是`null`。例如：
```
// 借用上面的例子'a'

a.indexOf("世界") // 结果是 3
a.indexOf("？") // 结果是 null
```

## replace
字符串的`replace:string(origin: string, new: string)`方法可以替换字符串的某一部分，返回替换成功的新字符串，例如：
```
// 借用上面的例子'a'

b: string = a.replace("世界", "Rime") // b的值是："你好，Rime！"
```

## forEach
字符串的`forEach:null(call: callable[string] -> any)`的方法可以遍历字符串内的每一个字符，让它执行一段代码。例如：
```9
// 借用上面的例子`a`

a.forEach((i) => print(i)) // 程序将会遍历输出：“你好，世界！”（换行分割）
```
> 实际上来讲，这段代码等同于
> ```
> for i in a {
> 	print(a)
> }
> ``` 
实际上，对象的`forEach`方法对任意的可迭代都存在。

### pad
字符串的`pad`方法可以自动生成固定长度的字符串，`pad(length: int, char: string = " ", position: Literal["left"， "right"])`，`length`决定了固定的长度，`char`决定了补充空白用的字符，`char.length`必须是`1`，`position`是决定补充空白的位置，`left`从字符串的开始（左侧），`right`从字符串的末尾（右侧）。
